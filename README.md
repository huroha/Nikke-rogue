# Nikke Rogue (가제)

포켓로그 스타일의 **웹 로그라이크 몬스터 배틀** 게임. 시스템만 참고한 오리지널 프로젝트로, 몬스터·기술·그래픽은 모두 자체 제작입니다.

> 다른 PC에서 이어서 작업하려면 [docs/HANDOFF.md](docs/HANDOFF.md)를 먼저 읽으세요.

## 실행

```bash
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm test          # 배틀 코어 테스트
npm run build     # dist/ 에 정적 빌드
```

`main` 브랜치에 push하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포까지 합니다.

## 현재 구현 (MVP)

- 스타터 3종 중 1마리 선택 → 웨이브마다 야생 몬스터와 1:1 턴제 전투
- 9개 속성 상성, 능력치/레벨 공식, 급소, 자속 보정, 랭크 변화, 흡수/반동/회복 기술, 선공 기술
- 포획 (보스 불가, 파티 최대 6), 교체, 쓰러지면 강제 교체
- 경험치 분배, 레벨업, 기술 습득(4개 초과 시 잊을 기술 선택), 진화
- 웨이브 클리어 후 보상 3택 1, 10웨이브마다 보스
- 웨이브 시작 시 자동 저장 (localStorage) → 타이틀에서 이어하기

## 구조

```
src/
  core/            # 렌더링과 무관한 순수 게임 로직 (테스트 대상)
    data/          #   종족, 기술, 상성표
    battle.ts      #   턴 진행 → BattleEvent[] 를 돌려줌
    damage.ts, ai.ts, monster.ts, run.ts, rewards.ts, balance.ts
  scenes/          # Phaser 씬 (타이틀, 스타터, 배틀, 진행, 보상, 게임오버)
  ui/              # 공용 위젯/테마
  assets/monsters/ # 몬스터 도트 그림 (아래 참고)
tests/             # vitest
```

배틀 로직은 상태를 바꾼 뒤 `BattleEvent` 목록을 돌려주고, 씬은 그 이벤트를 순서대로 연출만 합니다. 연출을 바꿔도 규칙이 깨지지 않고, 규칙은 브라우저 없이 테스트할 수 있습니다.

## 밸런스

수치는 `src/core/balance.ts` 에 모여 있습니다. 현재 값은 단순한 자동 플레이 봇으로 스타터별 200판씩 시뮬레이션해서 정했습니다 (중앙값 웨이브 20~30대).
